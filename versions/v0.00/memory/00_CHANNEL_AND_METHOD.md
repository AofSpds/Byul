## Research Discipline

### PRIOR-ART-FIRST
새 이론 발명이 목표가 아니다. 기존 formalism을 먼저 찾고, 현재 요구를 가장 적게 왜곡하는 선행 이론·모델을 우선한다.

### Intent Preservation + Solution Non-Locking
Owner의 직관을 바로 구현 지시로 바꾸지 않는다. 예: `Function을 primitive로 설계`가 아니라 `Object를 primitive로 두지 않고도 구성 가능한가?`처럼 연구 가능한 Challenge로 변환한다.

### Owner Recognition != Scientific PASS
Owner가 `이건데?`라고 느끼는 것은 중요한 질적 신호이나 독립적 과학 검증이 아니다.

### Premature Convergence 금지
실질적 차이가 있으면 계속 비교한다. 차이가 사라졌다면 억지 반론은 만들지 않는다.

### FACT / INTERPRETATION / HYPOTHESIS 분리
표준 이론의 사실, Owner의 가설, 이 채널의 추정, 구현 후보를 섞지 않는다.

## Memory / Handoff Rule

향후 승계 패킷은 길게 모든 내용을 반복하지 않고 `채널 구분 + 현재 살아 있는 핵심 가설 + 중요한 수정점 + 다음 탐구 위치` 중심으로 짧게 한다.

반면 이 저장소의 채널 메모에는 **가설이 어떻게 변했는지, 어떤 표현이 Owner correction으로 수정됐는지, 무엇이 아직 미결인지**를 상세히 기록한다.

## Current Interpretation of P-series

P-series의 정확한 canonical 문구는 이 저장소의 권한이 아니다. 현재 연구적 해석은 다음뿐이다.

- P-series는 특정 구현 모델을 지시하는 것이 아니라 구현이 벗어나면 안 되는 상위 원칙층이다.
- P-series를 만족하는 범위에서는 구현 representation이 상황에 따라 열려 있다.
- 후보 모델 간 mutation/공존/라우팅은 가능 후보이나 P-series를 자동 완화하거나 다시 쓰지 않는다.
