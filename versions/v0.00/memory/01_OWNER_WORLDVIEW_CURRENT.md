# 01. Owner Worldview — Current Non-Normative Hypothesis

## Status

`OWNER_EXPLICIT / HIGH-INTEREST_WORLDVIEW_HYPOTHESIS / NON_NORMATIVE / NOT_VALIDATED`

이 문서는 Owner의 현행 직관을 정확히 보존하기 위한 메모이며 ontology 선언이나 Requirement가 아니다.

## Philosophical Compression

Owner가 오래 유지한 철학적 배경에는 `제법무아 / 오온개공 / 연기설`과 구조적으로 닿는 직관이 있으나, 이것이 물리학·컴퓨터과학의 증명 근거는 아니다.

현재 computational translation 후보:

1. 고정 Object가 primitive일 필요는 없다.
2. 전체는 구성/과정/다발일 수 있고 높은 scale에서 하나처럼 보일 수 있다.
3. 현상은 조건·상호작용·결합을 통해 생기고 변하고 소멸한다.
4. 최근 가장 강한 고해상도 표현은 `무수한 국소 사상들의 합성망`이다.

## Mapping / Function History

초기 강한 직관:

`A => B`에서 `=>` 자체가 중요하다.

Owner 가설:

- 함수/사상은 함수를 바꿀 수 있다.
- 여러 사상이 합성된다.
- 값/Object도 사상적으로 표현 가능할 수 있다.
- Object는 primitive가 아니라 projection/materialization일 수 있다.

### Hidden-Object Problem

표준 함수 `f:A→B`는 이미 A/B Object를 전제한다. 따라서 `Function primitive`를 말하면서 Object를 숨겨 재도입할 위험이 있다.

후보로 pure arrow / typed morphism / object+morphism / objectless or identity-recovered morphism 등을 열어뒀으나 미결이다.

## Interaction-first → Micro-mapping Composition Network

한동안 `상호작용이 먼저일 수 있다`가 강해졌다. 이후 양방향 mapping bundle 후보를 거쳤다.

- `F={f1,f2,...}: A→B`
- `G={g1,g2,...}: B→A`

F/G가 역함수나 대칭일 필요 없이 coupling될 수 있다고 보았다.

그러나 Owner가 다시 더 고해상도에서 교정했다.

> 둘 사이를 하나의 함수 또는 커플함수로 묶고 있다는 느낌 자체가 이미 coarse-grained abstraction일 수 있다. 실제 세계관은 무수히 많은 작은 함수가 합성되는 쪽에 더 가깝다.

현재 강한 가설:

`micro mappings → composition → larger process/network → persistent pattern → Object / Persona / Protocol / Boundary view`

## Primitive Search

Owner 발언:

> primitive를 생각할 때는 최대한 고해상도가 맞지 않을까요.

단 `가장 작은 물리단위가 반드시 있다`는 전제는 없다.

현재 경쟁 후보:

- Event + Causal Order
- Local Mapping / Transformation
- Local Interaction
- Mapping + Composability + Composition
- Network Rewrite
- typed morphism family
- Object-first control

`하나의 primitive`가 아니라 최소 primitive algebra / 최소 문법일 가능성도 열려 있다.

## Self / Persona Continuity

Owner 핵심 표현은 `계승`이다.

`Me_T0 = Me_T1`보다 `Me_T0 → Me_T1`에 가깝다.

Owner 표현:

> 현재 매핑의 집합이 나라면 그 집합이 시간함수를 타고 계속 변화.

따라서 현재 가설에서 Self는 영속 substance보다 시간에 따라 변하는 mapping/process bundle이며 continuity는 identity보다는 succession/history에 가깝다.

Persona lifecycle stress candidate:

`INIT → interaction/history → differentiation → divergent adaptation → co-adaptation → merge → re-differentiation → succession`

좋은 World Model은 이를 special-case API가 아니라 underlying semantics에서 자연스럽게 표현할 수 있어야 한다는 요구 후보가 있다.

## Observation

Owner는 관측을 World Model 밖 privileged meta-operation으로 두지 않는 방향에 관심이 높다.

관측에도 source/target이 있으며 대상 쪽을 source, 관측자 쪽을 target으로 볼 수 있다는 직관이 있었다.

Owner correction:

- 관측 대상/관측자/결과를 영원한 Object로 볼 필요 없음.
- `타겟이 잠시 우리 인지에 맺힌 특정함수의 상태`
- `그 타겟이 영원하지 않지요 바로 다른 타겟으로`
- `찰나의 시간에 타겟을 관측할뿐 또는 그렇다고 착각할뿐`

후보 해석은 아직 분리 유지:

1. `DERIVED_TRANSIENT_STATE`
2. `COGNITIVE_REIFICATION`

## Time / Reciprocity

Owner가 양방향 primitive를 의심하게 된 핵심 이유는 시간이다.

Owner 표현:

- `1ms전의 나는 없습니다.`
- `동시는 동시가 아니다.`
- `내가 더 이상 그때의 내가 아닌데 양방향은 착각이 아닌가.`

초기 표현 `A↔B`를 고해상도로 펼치면:

`A_t0 → B_t1 → A_t2 → B_t3 ...`

가능성이 있다.

따라서 현재 강한 후보:

- 실제 causal mapping은 future-directed일 수 있다.
- 과거 A로 되돌아가는 것이 아니라 미래의 A 상태가 다시 나타난다.
- reciprocity는 primitive bidirectional edge가 아니라 time-extended causal pattern일 수 있다.

아직 최종 결론 아님.

## Absolute Time / NOW

최근 Causal Set 학습을 통해 Owner는 다음 구분을 명확히 받아들였다.

- 절대적 global NOW를 primitive로 둘 필요가 없다.
- 서로 인과적으로 비교 불가능한 사건에 절대적 선후를 부여하지 않는다.
- `비교할 필요가 없음`이 아니라 `인과적으로 비교 불가능`이다.
- 그렇다고 모든 시간구조가 주관적/임의적이라는 뜻은 아니다. causal order와 proper-time-like relational quantity는 객관적 구조가 될 수 있다.

## Minimum Physical Unit / Information Speed Hypothesis

Owner는 최소 시간/공간 단위를 반드시 가정하지 않는다.

다만 오래 가진 연구 후보:

> 최소단위의 국소사상이 primitive일 수 있다.

또 다른 Owner hypothesis:

> 정보 전달속도의 한계가 국소 사상의 처리/전달 한계와 관련될 수 있지 않을까.

이는 표준 상대론/Causal Set의 established claim이 아니다. 특히 왜 그런 local limit가 모든 관성계에서 동일한 `c`를 자연스럽게 만드는지가 강한 challenge다.

## Current Strongest One-line Worldview

> 현실을 충분히 높은 해상도로 보면 고정된 Object들이 먼저 있기보다 무수한 국소 사상/변환들이 합성되며, 우리가 Object·Self·Persona·관계라고 부르는 것은 더 높은 scale의 지속 패턴 또는 view일 수 있다.
