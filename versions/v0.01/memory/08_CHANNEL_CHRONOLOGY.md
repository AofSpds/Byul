## Research Evolution

1. `Mapping-first`: `A=>B`에서 arrow/mapping 자체를 중요하게 봄.
2. `Hidden-Object Problem`: `f:A→B`가 이미 A/B를 전제함을 발견.
3. `Interaction-first`: 상호작용 primitive 후보 강화.
4. `Opposite-direction bundles`: F:A→B / G:B→A coupling 후보.
5. `Time correction`: `1ms전의 나는 없습니다`, `동시는 동시가 아니다`; reciprocity를 time-extended causal pattern으로 보기 시작.
6. `Micro-mapping composition network`: A/B bundle 자체가 coarse-grained일 수 있다는 Owner correction; `무수한 국소 사상들의 합성망`으로 이동.
7. `Primitive resolution`: 높은 해상도 선호, 물리적 최소단위 존재는 미가정.
8. `Causal Set discovery`: event+causal order, no global NOW, order+number reconstruction에 강한 관심.
9. `Link/Chain/Antichain`: Link≠local transformation, longest chain/proper-time-like, antichain=비교불가를 학습.
10. `Causal Diamond/Reconstruction`: Owner 기존 추상화 아이디어와 유사성 인식.
11. `Reconstruction reliability challenge`: 어디까지 복원 가능한가, 열화되면 의미 있는가를 강하게 제기.
12. `Reconstruction classes`: EXACT/ANCHORED/STATISTICAL/VIEW-DEPENDENT/NON-RECOVERABLE.
13. `Complexity warning`: Link-only도 O(N²)에 근접할 수 있어 Causal Set은 자동 경량 storage가 아님.
14. `Complementary models`: Causal Set 하나로 전체 World Model을 맡기지 않고 Petri/Event/LTS/Rewrite 계열 비교.
15. `Petri/Event family`: possible behaviour / occurrence / conflict / resource / cycle / model mutation을 상호보완 family로 재구성.
16. `Index complement`: Causal/Event/LTS 일부는 semantic index/view, Petri는 executable behaviour model.
17. `Reverse compatibility`: exact inverse보다 synthesis; EXACT/SEMANTIC/APPROXIMATE/NON-RECOVERABLE.
18. `P-series freedom`: P-series를 벗어나지 않으면 implementation은 열려 있음.
19. `Situation routing`: Owner가 매우 좋다고 평가. 모델에 어울리는 상황을 사전 식별해야 함.
20. `R(S,M,L)`: Situation / Current Model State / Lifecycle Context 세 인자 후보.
21. `Lifecycle validation`: 단일 변환보다 장기 create→mutate→compose→split→merge→migrate→recover 검증 필요.
22. `Committee scenario outsourcing`: blind/model-attack/coverage-gap 공모 방향.
23. `MI-1`: fresh-instance 초기상태 복원 자체를 테스트할 가치 있음.
24. `Byul separation`: 연구 메모를 AAA 본체와 분리해 `AofSpds/Byul`에 보존.
25. `Version boundary`: v0.00 backup, v0.01 active research successor, v0.1부터 model implementation.

상세 복구가 필요하면 predecessor의 원본 chronology와 context backup을 읽는다.
