## Current Strongest Worldview

> 현실을 충분히 높은 해상도로 보면 고정된 Object들이 먼저 있기보다 무수한 국소 사상/변환들이 합성되며, 우리가 Object·Self·Persona·관계라고 부르는 것은 더 높은 scale의 지속 패턴 또는 view일 수 있다.

현재 압축 표현: `무수한 국소 사상들의 합성망`.

## Philosophical Background
- 제법무아 / 오온개공 / 연기설과 구조적 친화성이 있으나 물리/계산이론의 증명 근거가 아님.

## Mapping / Hidden Object
- `A=>B`에서 `=>` 자체가 중요하다는 직관.
- 함수/사상이 다른 함수를 바꿀 수 있음.
- 여러 사상이 합성될 수 있음.
- Object가 projection/materialization일 수 있음.
- `f:A→B`는 A/B를 미리 전제하므로 Hidden-Object Problem.

## Interaction → Composition Correction
- interaction-first 후보가 강해짐.
- opposite-direction mapping bundle `F:A→B`, `G:B→A` 후보를 거침.
- 이후 Owner가 A/B와 F/G 자체가 이미 coarse-grained일 수 있다고 correction.
- 최신: micro mappings → composition → larger process/network → persistent pattern → Object/Persona/Protocol/Boundary view.

## Primitive Search
- 최대한 높은 해상도에서 탐색.
- 최소 물리단위 존재는 전제하지 않음.
- `최소단위의 국소사상`은 가설.
- Event+Causal Order / Local Mapping / Interaction / Composition / Rewrite / typed morphism / Object-first control 경쟁 중.
- 하나의 primitive보다 최소 algebra/문법 가능성 열림.

## Self / Continuity
- 핵심 표현: `계승`.
- `Me_T0 = Me_T1`보다 `Me_T0 → Me_T1`.
- Self는 시간에 따라 바뀌는 mapping/process bundle일 수 있음.
- continuity는 identity보다 succession/history에 가까울 수 있음.

## Observation
- 관측도 World Model 내부 mapping일 가능성.
- 관측 target은 영속 Object가 아니라 transient observation slice일 수 있음.
- `DERIVED_TRANSIENT_STATE`와 `COGNITIVE_REIFICATION` 경쟁 해석 유지.

## Time / Reciprocity
Owner 표현:
- `1ms전의 나는 없습니다.`
- `동시는 동시가 아니다.`

`A↔B`보다 `A0→B1→A2→B3...`가 고해상도 표현일 수 있음.
Reciprocity는 primitive bidirectional edge보다 time-extended causal pattern일 가능성.

## Absolute NOW
- global absolute NOW를 primitive로 두지 않는 방향 강함.
- 인과적으로 비교 불가능한 사건에 절대 선후를 강제하지 않음.
- causal order와 proper-time-like 관계가 임의적이라는 뜻은 아님.

## Information Speed Hypothesis
- 정보 전달속도 한계가 local mapping processing/propagation limit와 관련될 수 있다는 Owner hypothesis.
- established physics claim 아님.
- 모든 관성계에서 동일한 c가 어떻게 나오는지가 강한 challenge.
