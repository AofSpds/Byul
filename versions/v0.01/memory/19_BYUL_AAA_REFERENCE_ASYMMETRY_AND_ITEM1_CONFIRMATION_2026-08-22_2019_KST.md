## Reference Direction Correction

The relationship is not a symmetric routine synchronization requirement.

- BYUL MAY and often SHOULD reference AAA current implementation/progress when it is relevant research input, because BYUL exists to improve/test models for AAA.
- AAA does NOT need routine awareness of BYUL progress and does not need to load BYUL state as part of normal AAA operation.
- AAA MAY reference BYUL only in special cases: model-upgrade review, explicit adoption/admission, investigation of a relevant BYUL result, or another Owner/AAA-directed need.
- Therefore no bidirectional always-on state synchronization, shared memory replication, or mandatory BYUL pointer should be added to AAA by default.
