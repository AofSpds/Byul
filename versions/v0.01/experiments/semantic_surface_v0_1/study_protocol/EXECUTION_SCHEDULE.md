## Global controls

- Visibility and conformance are independent tracks. Neither can repair or
  reinterpret a failed, missing, contaminated, or completed result in the other.
- Existing v0 files and memories are evidence and are never rewritten in place.
- Every future mutable worker has one unique branch, isolated repository or
  container, immutable base, write scope, actor, and result destination.
- No candidate, adapter, or C0 real-case run occurs before all prospective refs
  and the external holdout commitment freeze simultaneously.
- Reader bundles freeze before candidate construction and contain no study key,
  prior result, candidate, adapter, or result artifact.
- Integrity blockers are non-waivable for claim-bearing runs. Owner-authorized
  execution without them is a separately named
  `CONTAMINATED_PUBLIC_REHEARSAL` and returns `INSUFFICIENT_EVIDENCE`.
- All budgets are non-fungible and governed by `BUDGET_ACCOUNTING.md`.

## External coordination required before execution

The schedule cannot advance beyond protocol/spec preparation using one local
workspace alone. Claim-bearing execution requires:

- `EXTERNAL_COORDINATION_REQUIRED / V2-V3`: human readers, two model lineages,
  hidden assignment custody, dual graders, and immutable response storage;
- `EXTERNAL_COORDINATION_REQUIRED / F4`: external ACL store, independent
  selector/custodian/oracle reviewer, salted commitment witness, and access audit;
- `EXTERNAL_COORDINATION_REQUIRED / F5`: fresh result-blind adversarial review of
  exact successor refs;
- `EXTERNAL_COORDINATION_REQUIRED / F7-F8`: isolated repositories/containers,
  model/resource metering, and simultaneous result freeze; and
- `EXTERNAL_COORDINATION_REQUIRED / F9-F10`: blind graders, tie adjudicator,
  re-link controller, failure-triage panel, and—only if eligible—fresh successor
  holdout coordination.

Absent those controls, the only permitted terminal report is a protocol or
public-rehearsal report with `INSUFFICIENT_EVIDENCE` and no candidate, H3, C3,
validation, selection, merge, or production claim.
